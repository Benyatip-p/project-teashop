# project-teashop
Project สำหรับรายวิชา BE-FE
Tech-Stack: React, Taliwind CSS, Go, Docker

Domain Business: ระบบอีคอมเมิสสำหรับร้านขายชาโดยสามารถเลือกซื้อชาประเภทต่างๆตามจำนวนกรัม, อุปกรณ์ในการชงชา, สามารถเพิ่มสินค้าลงในตะกร้าสินค้าได้, ยังไม่สามารถชำระเงินได้จริง, มีระบบ Back office สำหรับ Admin ในการจัดการเพิ่ม,ลบ,แก้ไขสินค้าภายในร้าน มีแดชบอร์ดสำหรับดูรายงานการขายสินค้า สินค้าที่ขายดี 5 อันดับแรก สินค้าที่ใกล้หมดสต็อก
